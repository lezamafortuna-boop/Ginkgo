How Access Works (Roles)
You can implement role-based access so different people see different things.

Admin
Full access

Can manage everything

Can see all properties, leads, clients, tasks

Can manage agents

Agent
Can only see their assigned leads

Can only edit properties assigned to them

Can update statuses

Can add notes

Cannot delete other agents’ data

Viewer
Read-only access

For investors, partners, or assistants

This is extremely common in real estate CRMs.

How It Integrates With the Public Website
Here’s the magic:

✔ When management adds a property in the CRM
It automatically appears on the public website.

✔ When they update a property
The public listing updates instantly.

✔ When a customer fills a contact form
A lead is created inside the CRM.

✔ When an agent changes lead status
The CRM logs the activity.

✔ When a property is marked “sold”
It disappears from the public listings.

Everything is connected.
